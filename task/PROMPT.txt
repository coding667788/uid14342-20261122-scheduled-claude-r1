请实现一个离线模拟器，验证双中心安全网关是否能按规则准入连接。只读虚构接入事件，无套接字、真实密钥、攻击流量或设备控制。一个连接能进入受保护段之前，两中心必须分别发放可信准入部分，两份批准都须绑定同一设备、用户、信任策略代次、源段、目的段及有效区间。计算共同区间时按左闭右开。连接可绑定两个以上允许的入口中心作分区备用；政策可要求入口与业务签发中心不同，涉及分类降级时必须同时核对精确路由标签。任何中心的可信撤回只可缩短当前租约或禁用其中一个入口，禁止用迟到的旧批准重新打开。撤回事件带不可倒退中心序号；收到缺号时对相关场地保守关门，补齐后按序恢复，并始终保留已处理的撤回来源。
对每份申请登记跨中心不重叠的消息序号区间和使用代次。每个模拟接入事件带 (租约、代次、序号、源段、目的段、入口、请求摘要)，必须在 SQLite 同笔事务复核所有绑定、当前中心可信水位、交叠时限、路由限制后消费该序号；多个入口争同一个号只允许一个准入。批准消息可乱序到达，发布后的新代次从零开始并不允许旧代消息混入；同一序号同请求重放只返回原已持久化回执。一个入口丢失确认而重传时不得把不同摘要的接入判为无害重放。learn 更新中心事件，admit 判定单次接入，inspect 可回读任一历史提交。另提供 audit，对每个 LAN 分区模拟一个中心失联，分别输出仍可建立的条件与保密性拒绝原因，不能把缺号恢复期间的观察跳过。验证两批独立批准不能拼接、路由标签变化和入口撤回竞争、截止恰遇中心水位恢复、新代次仍被迟到旧准入引用、双入口重放、进程退出前后的原子回执；用独立小状态机核对各事件前缀。

用可直接执行的本地虚构接入案例交付模拟器。运行命令为 `python -m solution <命令> CASE.json`，需要读取或更新持久状态时还要提供 `--db DB.sqlite`。约定 stdout 为 UTF-8 JSON，相同逻辑案例必须得到相同结果；结构错误应返回错误码和字段位置。从空仓库编写，运行环境限 Windows 原生 Python 3.12、标准库和 CPU。README 需覆盖每个输入输出字段与复现命令，并提供 `python -m unittest discover -s tests -v` 可执行的断言测试。
